# نظام امتحانات كلية شرق النيل + لوحة الطقس (نسخة تجريبية)

هذا المشروع مبني بـ **React + Vite** ويحتوي الآن على واجهتين مستقلتين داخل نفس التطبيق:

1. **منصة امتحان تجريبية** (الوظيفة الأصلية)
2. **لوحة طقس عربية RTL**

> لا توجد أي مفاتيح API سرية داخل المشروع. جميع بيانات الطقس من خدمات Open-Meteo العامة المجانية.

## ما الذي تم تنفيذه؟

### أولًا: منصة الامتحان (كما هي)

- واجهة عربية RTL بعنوان **نظام امتحانات كلية شرق النيل**.
- شاشة دخول الطالب + تعليمات + أسئلة + مؤقت + شريط تقدم.
- حفظ محلي للإجابات في `localStorage`.
- تسليم المحاولة بحالة **قيد المراجعة**.
- شاشة مراجعة إدارية تجريبية.

### ثانيًا: لوحة الطقس

- بحث مدينة مع **اقتراحات تلقائية** واختيار مباشر من النتائج.
- دعم **تحديد الموقع الجغرافي** من المتصفح مع fallback للبحث اليدوي عند الرفض/الفشل.
- عرض الطقس الحالي:
  - درجة الحرارة
  - الحرارة المحسوسة
  - الرطوبة
  - سرعة الرياح واتجاهها
  - الهطول
- عرض الشروق/الغروب وتوقعات **7 أيام**.
- زر **تحديث** يدوي مع إظهار **آخر تحديث ناجح**.
- حالات واجهة واضحة: loading, empty, network/API error, invalid city.
- تصميم متجاوب للجوال وسطح المكتب مع تباين جيد وتحكمات قابلة للوصول عبر لوحة المفاتيح.

## API المستخدم

### Geocoding / Reverse Geocoding
- `https://geocoding-api.open-meteo.com/v1/search`
- `https://geocoding-api.open-meteo.com/v1/reverse`

### Forecast API
- `https://api.open-meteo.com/v1/forecast`

تم عزل استدعاءات API وتطبيع البيانات في:

- `src/services/weatherApi.js`

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## التحقق والجودة

```bash
npm run lint
npm run build
```

لا توجد بنية اختبارات آلية جاهزة حاليًا (مثل Vitest/Jest)، لذلك التحقق الحالي يعتمد على lint/build + التحقق اليدوي من الواجهة.

## كيفية اختبار لوحة الطقس يدويًا

1. افتح التطبيق ثم اختر **لوحة الطقس**.
2. اكتب اسم مدينة (مثل: الخرطوم) واختر نتيجة من القائمة.
3. جرّب زر **استخدام موقعي** ثم اسمح/ارفض الإذن للتأكد من سلوك fallback.
4. افصل الشبكة أو استخدم اسمًا غير صحيح للتحقق من رسائل الخطأ.
5. اضغط **تحديث** وتأكد من تغيير وقت آخر تحديث.

## حدود النسخة الحالية

- البيانات تعتمد على Open-Meteo وقد تختلف دقتها حسب المنطقة.
- لا يدعم هذا النموذج تنبيهات الطقس الخطيرة الرسمية.
- لا توجد دقة دقيقة على مستوى كل دقيقة زمنية.
- منصة الامتحان ما زالت بدون Backend حقيقي أو قاعدة بيانات مركزية.
